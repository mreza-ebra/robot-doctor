What this demonstrates

Source analysis, evidence-backed diagnosis, architecture extraction, and static re-verification of a deliberately introduced fault.

It does not establish time savings, customer traction, build success, runtime communication, or hardware compatibility. This synthetic scan publisher and observer are not a navigation stack.

Try your own project locally

Install the local beta from the repository using Docker or Python. Once it is running, choose a repository ZIP or HTTPS Git URL.

python3 -m pip install -e .
robot-doctor-web

Python 3.10.15 or newer is required. ROS and colcon are not required for static scans. Docker is an alternative installation path. The analyzer does not execute repository code or send ZIP contents to a cloud analysis service.

The live application offers filters and downloadable reports. Results disappear when the local app closes unless downloaded. Review the repository README and LICENSE before installation or evaluation.
